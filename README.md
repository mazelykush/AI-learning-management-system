# PROMPTVERSE AI

Gamified AI learning PWA guiding users from beginner to AI mastery through structured paths, interactive challenges, a prompt playground, and real-time AI feedback.

## Features
- 6-level curriculum (24 lessons) with good vs bad prompt examples
- Offline-ready inbuilt lessons
- Prompt playground with AI feedback
- Gamification: XP, streaks, achievements, leaderboard
- Onboarding assessment with personalized path
- Provider-independent AI abstraction layer
- Dark-first futuristic UI (Electric Cyan accent)

## Tech Stack
- Vite + React 19 + TypeScript
- Express server
- Tailwind CSS v4
- Drizzle ORM + PostgreSQL
- Firebase Auth
- Google Gemini (provider abstraction)
- Framer Motion

## Getting Started
1. Install: `npm install`
2. Configure env (see .env.example)
3. Run dev: `npm run dev`
4. Build: `npm run build`
